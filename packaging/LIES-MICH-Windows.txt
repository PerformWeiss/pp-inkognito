PP-Inkognito (Windows) - BITTE ZUERST LESEN
===========================================

Installieren
Doppelklicken Sie die Setup-Datei und folgen Sie dem Assistenten. Danach finden Sie PP-Inkognito im Startmenü (und auf dem Desktop,
wenn Sie das angekreuzt haben).

Warum die Sicherheitsmeldung?
Das Programm ist kostenlos und nicht mit einem Entwicklerzertifikat signiert (das kostet Geld pro Jahr). Deshalb zeigt Windows
beim ersten Öffnen "Der Computer wurde durch Windows geschützt". Das Programm ist nicht beschädigt.
- Klicken Sie auf "Weitere Informationen" und dann auf "Trotzdem ausführen".
- Falls Ihr Virenschutz warnt: Die Datei stammt von der offiziellen Projektseite; Sie können sie dort erneut herunterladen.

Arbeiten
Nach dem Start öffnet sich Ihr Browser mit dem Programm (der erste Start dauert etwas länger). Es läuft nur auf Ihrem Rechner,
ohne Internet. Ergebnisse liegen im Ordner Dokumente\Anonymisierungen. Beenden: im Programm oben rechts auf "Beenden" klicken.
Hinweise zum Datenschutz stehen im Programm unten unter "Datenschutz".
